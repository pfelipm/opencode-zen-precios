▶ ¿Qué hace esta app y cómo funciona?

¿Qué es este dashboard?

Esta Single Page Application (SPA) muestra la tabla de precios de modelos AI disponibles en OpenCode Zen de forma interactiva, con filtros por proveedor y tipo, ordenamiento por cualquier columna, y una vista de comparación para seleccionar modelos lado a lado.

¿De dónde salen los datos?

Al cargar la página, se intenta obtener el HTML desde https://opencode.ai/docs/es/zen/ y se parsean automáticamente tres tablas:

  • Tabla de endpoints — para obtener el Model ID de cada modelo
  • Tabla de precios — para entrada, salida, cache de lectura y cache de escritura (por 1M tokens)
  • Tabla de obsoletos — para marcar modelos con fecha de retirada

¿Qué pasa si falla la descarga?

Si la petición directa falla por CORS, se intentan proxies alternativos (allorigins.win, corsproxy.io). Si todo falla, se usan datos locales (fallback) embebidos en el archivo. El indicador de estado muestra si los datos son en vivo o locales.

Controles disponibles

  • Buscar — filtra por nombre o Model ID
  • Proveedor — OpenAI, Anthropic, Google, Otros
  • Tipo — Todos, Gratuitos, Pagados
  • Ordenar — clic en cualquier encabezado de columna
  • Comparar — marca checkboxes y pulsa “Comparar” para ver solo los seleccionados
  • Refresh — re-descarga los datos desde la fuente
